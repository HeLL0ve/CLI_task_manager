# CLI Task Manager

Простой консольный менеджер задач на C++20. Программа позволяет добавлять, просматривать, искать, отмечать как выполненные, удалять и сохранять задачи в файл.

## Возможности

- Добавление новых задач
- Просмотр списка задач
- Поиск задач по части названия
- Отметка задачи как выполненной
- Удаление задачи по номеру
- Сохранение и загрузка задач из `tasks.txt`

## Стек

- C++
- CMake

## Структура проекта

```text
CLI_task_manager/
|-- include/
|   |-- Task.h
|   `-- TaskManager.h
|-- src/
|   |-- main.cpp
|   |-- Task.cpp
|   `-- TaskManager.cpp
`-- CMakeLists.txt
```

## Сборка

### Через CLion

Откройте проект в CLion и запустите стандартную конфигурацию CMake.

### Через терминал

```powershell
cmake -S . -B build
cmake --build build
```

## Запуск

После сборки запустите исполняемый файл:

```powershell
.\build\CLI_task_manager.exe
```

Если проект собирается в CLion через папку `cmake-build-debug`, исполняемый файл обычно находится там:

```powershell
.\cmake-build-debug\CLI_task_manager.exe
```

## Доступные команды

| Команда | Описание | Пример |
|---|---|---|
| `add <текст>` | Добавить новую задачу | `add Купить молоко` |
| `list` | Показать все задачи | `list` |
| `find <текст>` | Найти задачи по части названия | `find молоко` |
| `complete <номер>` | Отметить задачу как выполненную | `complete 1` |
| `delete <номер>` | Удалить задачу | `delete 1` |
| `save` | Сохранить задачи в `tasks.txt` | `save` |
| `load` | Загрузить задачи из `tasks.txt` | `load` |
| `help` | Показать список команд | `help` |
| `exit` | Завершить программу | `exit` |

## Пример использования

```text
Welcome to CLI Task Manager
add Купить молоко
Task added.
add Закончить проект
Task added.
list
1. [ ] Купить молоко
2. [ ] Закончить проект
complete 1
Task completed.
list
1. [x] Купить молоко
2. [ ] Закончить проект
save
Tasks saved.
```

## Формат хранения

Задачи сохраняются в файл `tasks.txt` в формате:

```text
0|Купить молоко
1|Закончить проект
```

Где:

- `0` означает, что задача не выполнена
- `1` означает, что задача выполнена

## Особенности текущей реализации

- Нумерация задач в интерфейсе начинается с `1`
- Команды `delete` и `complete` ожидают корректный номер задачи
- При ошибочном вводе программа выводит сообщение об ошибке
- Автосохранения нет: для записи в файл нужно вызвать `save`
